# 水质数据爬取技术原理

## 一、项目背景

**目标网站**: 国家水质自动综合监管平台
**网址**: https://szzdjc.cnemc.cn:8070/GJZ/Business/Publish/Main.html

## 二、技术分析过程

### 2.1 初步观察

访问网站后，发现：
- 页面显示"实时数据"和"发布说明"两个入口
- 点击"实时数据"后跳转到 `/GJZ/Business/Publish/RealDatas.html`
- 数据并非直接写在HTML中，而是动态加载

### 2.2 排除静态爬取

尝试直接获取HTML内容：
```
<!DOCTYPE html>
<html>
<body>
    <div id="gridDatas"></ul>  <!-- 空的容器 -->
    <div id="loadPrompt">数据正在加载中...</div>
</body>
</html>
```

**结论**: 这是一个单页应用(SPA)，数据通过JavaScript异步加载，传统的 `requests` + `BeautifulSoup` 方式无法获取数据。

### 2.3 寻找API接口

#### 方法一：浏览器开发者工具

1. 按 `F12` 打开开发者工具
2. 切换到 `Network` 标签
3. 筛选 `XHR` 或 `Fetch` 请求
4. 刷新页面，观察数据请求

#### 方法二：分析JavaScript文件

查看网页引用的JS文件：
```html
<script src="/GJZ/Scripts/Publish/RealDatas.js?v3.1"></script>
```

获取该JS文件内容，找到关键代码：

```javascript
function getRealData(one, first) {
    _filter.action = "getRealDatas";
    $.ajax({
        type: 'POST',
        url: '/GJZ/Ajax/Publish.ashx',   // ← API接口
        data: _filter,
        dataType: "json",
        success: function (data) {
            // 处理返回数据
        }
    });
}
```

### 2.4 发现的API接口

| 属性 | 值 |
|------|------|
| URL | `https://szzdjc.cnemc.cn:8070/GJZ/Ajax/Publish.ashx` |
| 方法 | POST |
| Content-Type | application/x-www-form-urlencoded |

#### 请求参数

```javascript
{
    "action": "getRealDatas",     // 固定值，指定操作类型
    "AreaID": "440100",           // 区域ID，空为全国
    "RiverID": "1100000000",      // 流域ID
    "MNName": "江",               // 断面名称搜索关键词
    "PageIndex": 1,               // 页码
    "PageSize": 60                // 每页数量
}
```

#### 响应格式

```json
{
  "result": 1,
  "total": 188,          // 总页数
  "records": 1874,       // 总记录数
  "thead": [             // 表头
    "省份", "流域", "断面名称", "监测时间", "水质类别",
    "水温", "pH", "溶解氧", "电导率", "浊度", ...
  ],
  "tbody": [             // 数据行（二维数组）
    ["北京市", "海河流域", "鼓楼外大街", "02-18 14:00", "1", "7.9", ...],
    ["北京市", "海河流域", "广北滨河路（桥）", "02-18 14:00", "2", ...]
  ]
}
```

## 三、实现方案对比

### 方案一：浏览器自动化（Selenium/Playwright）

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = p.new_page()
    page.goto('https://szzdjc.cnemc.cn:8070/GJZ/Business/Publish/RealDatas.html')
    # 等待JS加载数据...
    data = page.content()
```

**优点**:
- 能处理JavaScript动态内容
- 模拟真实用户行为

**缺点**:
- 速度慢（需要启动浏览器）
- 资源占用大
- 依赖浏览器驱动

### 方案二：直接调用API（最终采用）

```python
import requests

response = requests.post(
    'https://szzdjc.cnemc.cn:8070/GJZ/Ajax/Publish.ashx',
    data={
        'action': 'getRealDatas',
        'AreaID': '',
        'PageIndex': 1,
        'PageSize': 60
    },
    verify=False  # 忽略SSL证书验证
)
data = response.json()
```

**优点**:
- 速度快（直接HTTP请求）
- 资源占用小
- 易于部署

**缺点**:
- 需要分析API接口
- API可能变化

## 四、关键技术点

### 4.1 SSL证书处理

该网站使用自签名SSL证书，需要忽略验证：

```python
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

response = requests.post(url, data=params, verify=False)
```

### 4.2 分页处理

通过判断 `total` 字段实现自动翻页：

```python
def get_all_data(self, max_pages=10):
    all_data = []
    page_index = 1

    while page_index <= max_pages:
        data = self.get_real_data(page_index=page_index)
        if not data or not data.get("tbody"):
            break

        all_data.extend(data["tbody"])

        total = data.get("total", 1)
        if page_index >= total:
            break
        page_index += 1

    return all_data
```

### 4.3 数据清洗

API返回的数据包含HTML标签，需要清理：

```python
# 原始数据
"<span title='原始值：7.87'>7.9</span>"

# 清理后
"7.9"
```

使用正则表达式提取显示值：

```python
import re

span_match = re.search(r"<span[^>]*title='([^']*)'[^>]*>(.*?)</span>", value)
if span_match:
    return span_match.group(2).strip()
```

### 4.4 编码处理

CSV文件使用 `utf-8-sig` 编码，确保Excel正确显示中文：

```python
with open(filename, 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.writer(f)
```

## 五、反爬措施分析

### 5.1 当前网站的反爬策略

| 措施 | 状态 | 应对方法 |
|------|------|----------|
| User-Agent检测 | 无 | 无需处理 |
| Referer检测 | 无 | 无需处理 |
| IP限制 | 未发现 | 无需处理 |
| SSL证书验证 | 有 | `verify=False` |
| 动态Token | 无 | 直接调用 |

### 5.2 潜在风险

1. **API变化**: 网站更新可能导致API参数变化
2. **访问频率**: 高频请求可能被限制
3. **数据时效**: 数据每20分钟更新一次

## 七、总结

本项目的核心在于：

1. **发现问题**: 识别出是动态加载的SPA应用
2. **定位API**: 通过分析JS代码找到真正的数据接口
3. **直接调用**: 绕过浏览器，直接HTTP请求获取数据
4. **数据清洗**: 处理HTML标签，提取有效数据

**核心理念**: 能用API就不用爬虫，能简单就不复杂。
