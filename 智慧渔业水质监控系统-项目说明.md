# 智慧渔业水质监控系统

## 项目概述

智慧渔业水质监控系统是一套专注于水质环境监测与数据可视化的管理平台。系统通过高精度传感器感知技术，实时采集水体温度、盐度、溶解氧、pH值等关键参数，结合物联网通信协议与智能算法，为现代渔业提供全方位的水质监测与预警解决方案。

**项目定位**：以数据展示为核心，通过可视化界面直观呈现水质监测数据，提供趋势分析与预警功能，辅助渔业养殖决策。

---

## 核心功能

### 1. 水质多参数实时监测
- **温度监测**：实时采集水体温度数据，精度±0.1℃
- **盐度监测**：监测水体盐度变化，评估海水/淡水环境
- **溶解氧监测**：实时追踪溶解氧含量，预警缺氧风险
- **pH值监测**：监测水体酸碱度，保障养殖生物生存环境

### 2. 数据可视化展示
- **实时数据看板**：以卡片形式展示当前水质参数
- **历史趋势图表**：通过折线图展示水质变化趋势
- **多维度对比**：支持多传感器数据对比分析
- **告警可视化**：告警信息高亮显示与历史记录

### 3. 智能预警系统
- **阈值告警**：支持多级告警机制，及时推送异常通知
- **趋势预测**：基于历史数据分析水质变化趋势
- **多维度分析**：综合温度、盐度、溶解氧、pH值进行联动分析

### 4. 设备管理功能（展示）
- **设备状态展示**：展示传感器与控制设备运行状态
- **历史记录查询**：设备控制日志与告警记录查询
- **设备信息管理**：设备基础信息与位置信息展示

## 核心模块设计

### 1. 假数据生成模块

**功能**：
- 自动生成符合实际场景的传感器数据
- 支持自定义数据范围与波动规律
- 定时更新模拟实时数据采集

**实现示例**：
```python
# backend/core/data_generator.py
import random
from datetime import datetime
from faker import Faker

fake = Faker('zh_CN')

class SensorDataGenerator:
    """传感器数据生成器"""

    @staticmethod
    def generate_temperature():
        """生成温度数据 (18-35℃)"""
        base = 26.0
        return round(base + random.uniform(-3, 5), 1)

    @staticmethod
    def generate_salinity():
        """生成盐度数据 (30-40‰)"""
        base = 35.0
        return round(base + random.uniform(-2, 3), 1)

    @staticmethod
    def generate_dissolved_oxygen():
        """生成溶解氧数据 (5-10 mg/L)"""
        base = 7.0
        return round(base + random.uniform(-1.5, 2), 1)

    @staticmethod
    def generate_ph():
        """生成pH值数据 (6.5-8.5)"""
        base = 7.5
        return round(base + random.uniform(-0.8, 0.8), 1)

    @staticmethod
    def generate_sensor_data():
        """生成完整的传感器数据"""
        return {
            'device_id': f'sensor_{random.randint(1, 10):03d}',
            'temperature': SensorDataGenerator.generate_temperature(),
            'salinity': SensorDataGenerator.generate_salinity(),
            'dissolved_oxygen': SensorDataGenerator.generate_dissolved_oxygen(),
            'ph': SensorDataGenerator.generate_ph(),
            'timestamp': datetime.now().isoformat()
        }

    @staticmethod
    def generate_historical_data(hours=24):
        """生成历史数据"""
        data = []
        for i in range(hours):
            data.append({
                'time': f'{i}:00',
                'temperature': SensorDataGenerator.generate_temperature(),
                'salinity': SensorDataGenerator.generate_salinity(),
                'dissolved_oxygen': SensorDataGenerator.generate_dissolved_oxygen(),
                'ph': SensorDataGenerator.generate_ph()
            })
        return data
```

```sql
-- 设备表
CREATE TABLE devices (
    id INT AUTO_INCREMENT PRIMARY KEY,
    device_id VARCHAR(50) UNIQUE NOT NULL,
    device_name VARCHAR(100),
    device_type VARCHAR(20),
    location VARCHAR(200),
    status VARCHAR(20),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 传感器数据表（仅用于存储历史记录，主数据由生成器实时生成）
CREATE TABLE sensor_data (
    id INT AUTO_INCREMENT PRIMARY KEY,
    device_id VARCHAR(50),
    temperature DECIMAL(4,1),
    salinity DECIMAL(4,1),
    dissolved_oxygen DECIMAL(4,1),
    ph DECIMAL(3,1),
    recorded_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_device_time (device_id, recorded_at)
);

-- 告警记录表
CREATE TABLE alerts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    device_id VARCHAR(50),
    alert_type VARCHAR(50),
    alert_level VARCHAR(20),
    message TEXT,
    value DECIMAL(10,2),
    resolved BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 快速开始

### 后端启动

```bash
# 1. 创建虚拟环境
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置数据库（编辑 settings/development.py）
# 4. 初始化数据库
python manage.py migrate

# 5. 创建超级用户
python manage.py createsuperuser

# 6. 启动开发服务器
python manage.py runserver

# 7. 启动定时任务（可选，用于自动生成数据）
celery -A aquaculture worker -l info --beat
```

### 前端启动

```bash
# 1. 安装依赖
cd frontend
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器访问
http://localhost:5173
```
